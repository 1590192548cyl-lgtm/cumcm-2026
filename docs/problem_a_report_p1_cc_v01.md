# 问题 1 结果报告：预热平衡阶段药材温度与水分浓度

## 1. 模型

药材按一维轴对称柱体处理，控制方程为耦合的非稳态导热与水分扩散方程：

```
rho*cp*dT/dt = (1/r) d/dr( k r dT/dr )
dC/dt        = (1/r) d/dr( D r dC/dr ),   D = 7e-9 exp(-0.89/C)
r = 0 : dT/dr = dC/dr = 0
r = R : -k dT/dr = h (T - T_air(t)),  -D dC/dr = km (C - C_air(t))
T(r,0) = 28 摄氏度,  C(r,0) = 2.55 kg/kg
```

边界条件 T_air(t)、C_air(t) 由附件 1 分段线性插值给出；物性取附录 2。

## 5. 结果解读

- 温度：表面先升温、中心滞后。t = 1800 s 时中心 33.5755 摄氏度、表面 36.7856 摄氏度，与烘房空气（此时 41.51 摄氏度）仍有明显温差，中心与表面温差 3.2 K，说明内部导热梯度不可忽略，集总参数法不适用。
- 水分：中心 2.5500 kg/kg 基本不变，表面由 2.55 降到 1.5102 kg/kg；水分变化集中在距表面 5 mm 量级的薄层内（r = 1.5 cm 处仅降低 0.17 kg/kg），30 min 远不足以改变整体含水率。
- 物理原因：热扩散比水分扩散快约 34 倍（Luikov 数约 0.029），因此该阶段是典型的"温度基本走完、水分刚起步"。

## 7. 对流传质边界条件口径（km_scale）的敏感性

题目给出的药材含水率是干基含水率，而空气水分浓度是绝对湿度，二者基准不同，因此 `-D dC/dr = km_scale * km * (C - C_air)` 中的口径需要显式声明。本模型采用与传热完全类比的第三类边界条件（`km_scale = 1`）。

**(a) 对问题 1 结果表的影响：只集中在最外层 2~3 列。**

| 位置 | km_scale=0.1 | km_scale=1（基线） | km_scale=10 | km_scale=820 |
|---|---|---|---|---|
| r = 2.0 cm（表面） | 2.4082 | 1.5103 | 0.2093 | 0.0352 |
| r = 1.9 cm | 2.4442 | 1.7808 | 1.0612 | 1.0457 |
| r = 1.8 cm | 2.4735 | 1.9938 | 1.4494 | 1.4329 |
| r = 1.5 cm | 2.5500 | 2.5497 | 2.5490 | 2.5489 |
| r = 1.0 cm | 2.5485 | 2.5383 | 2.5169 | 2.5141 |
| r = 0（中心） | 2.5500 | 2.5500 | 2.5500 | 2.5500 |

相对基线（km_scale = 1），`r <= 1.0 cm` 范围内的最大差异仅 0.0242 kg/kg（初值 2.55 kg/kg 的 1% 以下），中心差异 2.94e-05 kg/kg；差异全部集中在 `r >= 1.8 cm` 的外层。

**(b) 对烘干时长的影响：放大只快 7%，且很快饱和；取小则会定性改变结论。**

| km_scale | 0.1 | 1.0（基线） | 10.0 | 820.0 |
|---|---|---|---|---|
| 表面降到 0.15 的时刻 | 110.1 h | 12.6 h | 2.5 h | 0.0 h |
| 整体降到 0.15 的时刻 | 144.5 h | 57.2 h | 53.2 h | 53.2 h |
| 24 h 时的中心含水率 | 1.37 | 0.24 | 0.21 | 0.21 |

读法：把口径放大到 820（相当于外部阻力的内扩散控制极限），烘干时长只从 57.2 h 降到 53.2 h（−7%），而且 km_scale ≥ 10 之后已经饱和——说明内部扩散始终是主控环节，外部边界阻力不是瓶颈。反过来，把口径缩小到 0.1（Bi_m ≈ 0.12），外部传质成为瓶颈，24 h 时中心含水率还有 1.37 kg/kg，整体要 144.5 h，与题干「2~3 天」直接矛盾。所以 `km_scale = 1` 不只是「稳妥的折中」，而是**唯一与题干自洽的取值**。

**(c) 界面系数平均方式的收敛对照（这条结论的可信度在这里）。**

有限体积法里两个相邻控制体界面上的传导率，可以用算术平均也可以用调和平均，两者都是相容格式、细网格上收敛到同一个值。但**粗网格上调和平均会把强非线性区（表面干壳）的传输能力压得过低**，容易得出定性的错误结论。实测：

| 网格层数 | km=1 算术 | km=1 调和 | km=820 算术 | km=820 调和 |
|---|---|---|---|---|
| N = 320 | 57.190 | 57.617 | 53.140 | 174.75 |
| N = 640 | 57.211 | 57.290 | 53.200 | 106.42 |
| N = 1280 | 57.218 | 57.236 | 53.227 | 75.06 |
| N = 2560 | 57.221 | 57.225 | 53.240 | 61.55 |

两点结论：其一，km = 1 时两种平均在 N = 2560 收敛到同一个值 57.22 h，我们生产用的算术平均在 N = 640 就是 57.21 h，已经落在收敛值上。其二，km = 820 的调和平均给出的 174.75 h（N = 320）**是没有收敛的假象**，随着网格加密单调下降到 61.55 h，朝算术平均的 53.24 h 靠拢。因此本节的敏感性必须用已收敛的口径计算，早期版本用粗网格调和平均得出的「放大口径反而更慢」是错误结论，已作废。
