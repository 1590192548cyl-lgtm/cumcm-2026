## 3. 曾出现的错误结论（已作废）

中间版本在 320 层、调和平均下得到"传质口径放大反而使烘干变慢、$\kappa=1$ 附近是极小点"
的结论并写入报告。后续补做网格收敛对照，发现 $\kappa=820$ 时调和平均的结果随网格加密
从 174.75 h 单调降到 61.55 h，朝算术平均的 53.24 h 靠拢，属未收敛的中间结果。
结论已修正为：放大口径只使烘干时长缩短约 7%，且 $\kappa\ge10$ 后饱和；取小到 0.1
才会定性改变（144.5 h）。

**教训**：比较两种离散格式之前必须确认两边都已收敛，否则网格误差会被误读为物理效应。
