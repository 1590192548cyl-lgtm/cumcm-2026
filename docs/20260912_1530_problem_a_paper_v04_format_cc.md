## 改动内容

   规范要求"不设置装饰性页眉"，图形与表格也"避免默认软件配色"，此类填充框不在规范之内。
3. 4 处 `\resultbox{问题 k 核心结论}{...}` 还原为普通段落：去掉框与标题，保留文字。
   位置分别在问题 1、2、3、4 的表格之后。
4. `hyperref` 的 `urlcolor` 由蓝色改为黑色，避免正文出现装饰色。
